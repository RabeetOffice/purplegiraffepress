Blog cover images
=================

Drop one cover image per post into this folder, using the EXACT filenames
below (the code already points at these paths). Recommended size: ~1200x800px,
.webp format. The card, hero cover and "more from the blog" carousel all use
the same file.

Expected files:

  why-every-childrens-story-deserves-custom-illustration.webp
  step-by-step-journey-publishing-your-first-childrens-book.webp
  power-of-storytelling-how-childrens-books-shape-young-minds.webp

To change a filename or use .jpg/.png instead, update the matching 'image'
value in includes/blog-data.php.
